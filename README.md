# Arkfall — прототип боя (этап 0)

Top-down action roguelike. Phaser 3 + TypeScript + Vite. Все числа боя — в `src/data/*.json`, формулы GDD §5–6 — в `src/core/formulas.ts`.

## Запуск
```
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты формул
npm run build      # tsc + vite
npm run test:e2e   # дымовой Playwright (нужен npx playwright install)
```

## Параметры URL
`?tier=3&room=5&seed=42&debug` — Тир, комната, сид, отладка хитбоксов.

## Ворота этапа 0
- Средний TTK обычного моба 0,6–1,5 с (показан в HUD справа сверху).
- Каждая атака врага телеграфируется ≥ 0,4 с (контур → заливка).
- Бой «приятен» PM после 10 минут — субъективная проверка, фиксируется в GDD.

## Золото и Торговец (пакет 25)
Золото падает в кошелёк сразу при убийстве (без подбора с пола) и сгорает в конце забега. Дверь «Торговец» — обычная комната, после зачистки открывается лавка:
3 предмета, лечение, +1 реролл Руны, обновление витрины (цена растёт), продажа из рюкзака. Все цены и доход — `formulas.json` → `gold`, `shop`;
доход и цены масштабируются одним множителем Тира, поэтому покупательная способность от Тира не меняется.

## Эхо и Лавка Ковчега (пакет 26)
Эхо — постоянная валюта: Логово элиты 5, боссы актов 40/50/60, ×(1+0,4(T−1)), +30 % за живой выход; при смерти заработанное тоже едет домой.
Тратится в хабе (L): 3 предмета за Эхо (ассортимент меняется каждые 3 забега, цены привязаны к открытому Тиру) и сброс скиллов
(50 Эхо; все пройденные милстоуны выбираются заново). Числа — `formulas.json` → `echo`.

## Бестиарий (пакет 27)
8 врагов + босс, состав по актам — `rooms.json` → `compositionByAct`. Акт 1: Рвущийся, Стрелок, Молот. Акт 2: + Подрывник (взрыв при подходе и после смерти,
фитиль телеграфируется), Копейщик (длинный рывок, после — уязвим ×1,5, жёлтый). Акт 3: + Призыватель (зовёт Рвущихся, 1 на волну),
Щитоносец (урон с фронта ×0,25, дуга щита видна), Кружащий стрелок (орбита + веер из 3 снарядов). Посмотреть: `?tier=1&seed=3&room=21`.

## Скиллы и Руны — полный пул MVP (пакет 28)
10 скиллов (+ Жало ответа: уклонение сквозь удар = парирование; Эхо-удар: замах на месте, AoE + оглушение; Призрачный клинок: спутник на 10 с)
и 31 Руна из 32. «Магнит» не в пуле: подбора с пола нет (см. `UNIMPLEMENTED_FACETS`). Руны скиллов живут в `Mods` блоками по скиллу.
Проверить скилл: `?tier=1&seed=3&room=2&skills=echo_strike,blood_rhythm`.

## Проверка MVP (пакет 29)
`tests/sim/fullrun.test.ts` — headless-забег на 30 комнат на Тирах 1–3: три босса, все 8 врагов, победа (герой неуязвим — это проверка потока, не выживания).
`tests/unit/balance.test.ts` — ворота баланса по формулам: максимум за удар, TTK обычных и тяжёлых с ожидаемым билдом Тира (`ttkTarget.buildDamagePerTier`).
Правка пакета 29: `hpTierExp` 1,25 → 0,85, `dmgTierExp` 0,9 → 0,6 (Тир 3 был с ваншотами), урон/HP нескольких врагов — см. `_tierNote`.

## Графика G1 — атлас 32 px
`python3 tools/sprites/gen.py` собирает `public/sprites/atlas.png` + `atlas.json` (копия в `src/data/` для headless) из примитивов: герой — тёмный рыцарь,
бестиарий подземелья (гуль, культист, огр, гоблин-подрывник, скелет-копейщик, некромант, скелет-латник со щитом, летающий глаз, вождь огров), пол/стены, снаряды.
Кадры `<id>_idle0/1`, `_walk0/1`, `_attack`; анимации создаёт BootScene. Пол и стены — Blitter; в headless рендерера нет, поэтому там остаётся сетка.
Скриншот арены после `npm run test:e2e` — `test-results/arena-g1.png`. Нужен Python 3 с Pillow (`pip install pillow`) только для перегенерации атласа.

## Графика G2 — формы комнат, свет, масштаб
12 форм комнат в `src/data/layouts.json` (сетка 32×18 по 40 px; `#` колонна блокирует всё, `~` яма блокирует только ходьбу). Босс и комната 1 — «Зал»,
остальные — по сиду. Враги обходят препятствия рулением (`RoomGrid.steer`), без поиска пути. Посмотреть форму: `?tier=1&seed=3&room=2&layout=3`.
Спрайты ×1,5 (`SPRITE_SCALE`), хитбоксы прежние. Факелы на верхней стене и свет героя — `glow`-текстура с ADD-смешиванием (только с рендерером).

## Графика G3 — сок и настройки
Частицы по материалу врага (кровь, кость, ихор, искры, магия) при ударе и гибели; отдача формой; тела врагов остаются и тают; послеобразы рывка;
вспышка экрана и тряска при уроне герою; тряска от ударов тяжёлых и босса. Всё отключается в «Настройках» (O в хабе и в меню паузы) — `src/meta/Settings.ts`,
localStorage `arkfall.settings.v1`. Тряску вызывать только через `shake()` из Settings.

## Графика G4 — скин UI
`src/ui/theme.ts`: палитра (камень, багрянец, золото, лёд), `panel`, `button`, `heading`, `backdrop`. Все экраны берут рамки и кнопки отсюда.
Хаб: герой в свете факелов слева, панель забега справа. Удары, цепь Разряда, Эхо-удар, взрыв барьера и слэмы врагов уважают колонны (`RoomGrid.hasLos`).

## Графика G5 — иконки и портрет
Иконки Рун (`rune_<id>`) и предметов (`item_<id>`) — кадры 16×16 в том же атласе: символ + цвет в `RUNE_ICONS` / `ITEM_ICONS` в `gen.py`. Используются в HUD,
карточках Рун, снаряжении и лавках. Портрет босса (`portrait_<id>`) — у полосы HP босса. Тест `atlas.test.ts` следит, что у каждой Руны/предмета/врага кадры есть.

## Боссы актов (пакет 30)
`rooms.json` → `bossByAct`: Молот Ковчега (слэм, фаза 2 — кольцо), Костяной жрец (орбита, веер, каждые 4 удара зовёт скелетов; фаза 2 — телепорт от героя,
веер из 5, зовёт латников), Страж Бездны (рывок через комнату, уязвим после; фаза 2 — два рывка подряд и кольцо). `Boss.ts`: общий переход фаз + хуки `onStrike`/`onRecover`.
Посмотреть: `?tier=1&seed=42&room=20` и `room=30`.

## Звук (пакет S1)
`src/audio/sfx.ts` — всё синтезируется Web Audio, файлов нет. Игра шлёт `game.events.emit('sfx', name)`; рецепты в `RECIPES`. Эмбиент — гул + капли.
Старт по первому клику/клавише (автозапуск). Громкости — в настройках (5/6). В headless модуль молчит.

## Прогрессия героя (пакет 31)
Закалка по уровню (`formulas.json` → `heroGrowth`): урон +1,2 %, HP +1,2, откаты −0,3 % за уровень (потолок −30 %). Очки улучшений — 1 за 5 уровней,
тратятся в хабе (U) на слоты скиллов по схеме `upgradeSlots`; скиллы читают `mods.skill[id]` (урон, откат, область, длительность, снаряды, заряды).
Сброс скиллов возвращает очки. Проверить закалку: `?tier=1&seed=3&room=2&level=21`.

## Эффекты атак (пакет 32)
Полумесяц удара (`fx_slash`, 3 кадра, поворот по прицелу, масштаб по дальности), ветвистая молния с ореолом и искрами у Разряда, воронка частиц у Колодца,
шипы из земли у Шипастой земли, кольцо ударной волны (`fx_ring`) у Эхо-удара, Барьера и взрывов, искры в конце рывка. Кадры — в атласе, ореолы — ADD-смешивание.

## Пакет 33
Никто не живёт в колонне: каждый кадр тело внутри препятствия выталкивается на ближайшую свободную клетку (`ArenaScene.unstick`) — против рывков, отбрасывания и толкотни коллайдера.
Анимация атак врагов и боссов без новых кадров: замах — сжатие формы с нарастанием, удар — резкий выпад и возврат (`Enemy.updatePose`).

## Правила кода (выучены на баг-репортах)
- `Blitter` не умеет масштаб: в WebGL кадры рисуются 1:1, что бы ни стояло в `setScale`. Тайлы с масштабом — через `RenderTexture` (пол) или обычные `Image` (препятствия).
- Порядок сцен в `main.ts` = порядок отрисовки. Сцена, которую `launch()`-ят поверх арены, должна стоять в списке ПОСЛЕ `arena` и `hud` (или вызывать `bringToTop`), иначе она рисуется под ареной и выглядит «не открывшейся». Headless-тесты это не ловят — там нет рендера.
- Любая подписка на `this.game.events` снимается в `this.events.once('shutdown', …)`. Иначе остановленная сцена продолжает получать события и пишет в уничтоженные объекты.
- Переходы между экранами через `scene.start` всегда идут после явной остановки оверлеев (`facet`, `door`, `pause`, `summary`).
- Не использовать `TileSprite` — после `scene.stop` он получает холст без 2D-контекста из пула.
- Все числа — в `src/data/*.json`; код читает их, а не хранит.

## E2E локально без скачивания браузера
```
npm run build
npm run test:e2e          # использует системный Microsoft Edge
set PW_CHANNEL=chrome && npm run test:e2e   # или Google Chrome
```

## Симуляция без браузера (tests/sim)
`npm test` теперь гоняет и headless-симуляцию: Phaser запускается под Node (jsdom + canvas), время продвигается вручную,
клавиши эмулируются. Так проверяются переходы комнат, Грани, двери, смерть и босс. Если `npm install` не смог собрать
пакет `canvas`, юнит-тесты всё равно работают — упадут только `tests/sim`.
